# 3d-trajectory-analyzer
3D Trajectory Analyzer software to track position of a ball in the padel game

## Run with uv

Install uv with:

```bash
pip install uv
```

Install correct python version (defined in .python-version) with

```bash
uv python install
```

Create a virtual environment with the downloaded Python version with

```bash
uv venv
```

Install the requirements in the virtual environment with

```bash
uv pip install -r requirements.txt
```

Run the code (and automatically activate the virtual environment)

```bash
uv run main.py
```
